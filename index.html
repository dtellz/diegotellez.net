02 / approach

How I approach the work

AI changes the workflow. I’m accountable for the outcome.

  1. 01

    Understand the problem()

    Get close to the user. Question the requirement, identify the constraints and define what a useful result looks like.

  2. 02

    Design the system()

    Break the problem down. Make trade-offs around cost, consistency, reliability and maintenance explicit. Start with the simplest architecture that fits.

  3. 03

    Build with AI()

    Give agents bounded tasks and the context to do them well. Use them to explore, implement and refactor. Know when a direct solution is better.

  4. 04

    Verify the solution()

    Read the code. Test the assumptions and failure paths. Check security, debug the root cause and build evidence that the system behaves correctly.

  5. 05

    Own the result()

    Follow the change into production. Observe how it performs, measure it against the original need, communicate what changed and keep learning.

↳ The measure of success: useful software that holds up in the real world.
